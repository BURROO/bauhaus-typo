Wenn es auch ohne funktioniert umso besser!

    Open a terminal/command prompt.
    Go to the folder that contains your index.html (and style.css, IMG/, etc.):
    Code

    cd /path/to/your/project

    Start the local server (works fully offline):
    Code

    python -m http.server 8000

    In Chrome, open: http://localhost:8000/index.html
